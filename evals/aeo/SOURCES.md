## Sources for evals 101–108 (checked 9 October 2026)

## Google Search Central
- AI features and your website (updated 2025-12-10): https://developers.google.com/search/docs/appearance/ai-features. No special requirements for AI Overviews/AI Mode; a page must be indexed and snippet-eligible to be a supporting link. (104)
- Spam policies: https://developers.google.com/search/docs/essentials/spam-policies. Scaled content abuse (gen AI; "automated transformations like ... translating" appears in the scraping example, so for self-translation it describes a risk, not a ban); link spam (optimized anchor text in press releases). (103, 105, 107)
- Using generative AI content: https://developers.google.com/search/docs/fundamentals/using-gen-ai-content. AI content must meet Search Essentials and spam policies; review accuracy, including metadata and structured data; consider explaining how content was created. (103)
- Google Search Central blog, Feb 2023, "Google Search's guidance about AI-generated content": https://developers.google.com/search/blog/2023/02/google-search-and-ai-content. "Appropriate use of AI or automation is not against our guidelines." (103)
- Creating helpful, reliable, people-first content: https://developers.google.com/search/docs/fundamentals/creating-helpful-content. E-E-A-T isn't a specific ranking factor; more weight on YMYL; Who/How/Why; raters don't directly affect rankings. (102, 103)
- General structured data guidelines: https://developers.google.com/search/docs/appearance/structured-data/sd-policies. Don't mark up content that isn't visible; must truly represent the page; don't mislead. (102)
- Review snippet: https://developers.google.com/search/docs/appearance/structured-data/review-snippet. Self-serving reviews for LocalBusiness/Organization aren't eligible for stars. (108)
- Dataset: https://developers.google.com/search/docs/appearance/structured-data/dataset. Aimed at Dataset Search; name and description required. (107)
- Site moves with URL changes: https://developers.google.com/search/docs/crawling-indexing/site-move-with-url-changes. Use 301/308; redirect to the final destination; mass redirects to the home page may be soft 404s; keep redirects at least 1 year; Change of Address is for domain/subdomain moves only. (104)
- Consolidate duplicate URLs: https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls. rel=canonical and redirects are strong signals; don't use robots.txt or noindex for canonicalization. (101)
- Build a sitemap: https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap. lastmod is used only if consistently accurate; priority/changefreq are ignored. (101)
- JavaScript SEO basics: https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics. Not all bots can run JavaScript; server-side or pre-rendering is recommended. (101)
- Robots meta tag: https://developers.google.com/search/docs/crawling-indexing/robots-meta-tag. noarchive is no longer used by Google; nosnippet applies to AI Overviews/AI Mode. (106)
- Managing multi-regional and multilingual sites: https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites. Language is detected from visible content, not lang/URL; avoid automatic language redirects; don't use IP analysis to adapt content. Says nothing about machine translation. (105)
- Indexable file types: https://developers.google.com/search/docs/crawling-indexing/indexable-file-types. PDF is supported. (107, reference answer only)
