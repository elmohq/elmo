Create a payment

To create a payment, send a POST request to /v1/charges with an amount in cents and a card_token.

curl https://api.quillpay.dev/v1/charges \
  -u sk_live_xxx: \
  -d amount=2000 \
  -d currency=usd \
  -d card_token=tok_visa

Parameters

NameTypeDescription
amountintegerAmount in the smallest currency unit.
currencystringThree-letter ISO code.
card_tokenstringToken from Quillpay.js v1.
