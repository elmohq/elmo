## How limits apply

- **Brands** and **tracked prompts** are organization-wide pools. A prompt consumes a slot only while it is enabled.
- **Standard platforms** are selected per brand. Basic, Pro, and Business choose exactly four from the standard menu; Starter has one fixed ChatGPT target.
- **Claude prompts** are a separate organization-wide assignment pool on Pro and Business. Each assignment must refer to an enabled prompt already inside the standard prompt pool.
- **Seats** are unlimited on every plan. Workspace owners and admins manage billing and tracking; members can view plan information.
- **API access** is included on every plan. Keys belong to the workspace and stop authorizing requests when workspace access is inactive.

Changing to a smaller plan is blocked while enabled brands, prompts, platform selections, or Claude assignments exceed the new limits. Reduce usage first, then retry the plan change.

## Custom plans

Custom contracts can set independent brand and prompt limits, targets, per-target cadence and replication, Claude allowances, and usage ceilings. They can also include GPT-5 Search, web-search-enabled API targets, and sampling up to seven times daily.

Custom plans are operator managed instead of self-service. Contact [sales@elmohq.com](mailto:sales@elmohq.com?subject=Elmo%20Cloud%20custom%20plan) to design one.
