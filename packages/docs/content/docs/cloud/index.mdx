Elmo Cloud is the managed way to run Elmo. Elmo operates the database, workers, provider integrations, upgrades, and billing while your team uses the same transparent AI visibility product available in the open-source edition.

## Choose how to run Elmo

| Deployment | Best for | You manage |
|---|---|---|
| **Self-hosted** | Teams that want the free, MIT-licensed product on their own infrastructure | Hosting, upgrades, and provider accounts |
| **Elmo Cloud** | Teams that want tracking without operating the stack | Brand, prompts, competitors, and tracking choices |
| **White label** | Enterprises and agencies that need their own brand, domain, and SSO | Customer relationships and workspace configuration |

Cloud plans include unlimited seats and organization-scoped API access. Report generation is available in self-hosted and white-label deployments, but is not part of Elmo Cloud.
