Claude tracking is a separate prompt allowance on Pro, Business, and eligible custom plans. It supplements the standard platform selection instead of replacing one of the four standard targets.

## Choose a mode per prompt

Each Claude assignment runs once daily in one of two modes:

- **Base model** asks Claude without web search. Use it to measure the model's existing representation of your brand.
- **Native web search** lets Claude use Anthropic's search tool with a bounded search budget. Use it to measure a web-grounded answer and its citations.

You can choose a different mode for each prompt and change it later. Elmo stores the two modes as distinct tracking targets, so their results and usage cannot be mixed accidentally.

## Allowances and add-ons

Pro includes 20 Claude prompt assignments and Business includes 30. Extra assignments cost $5 per prompt each month, or $50 per prompt on annual billing. Add or remove capacity from **Plan & usage** without leaving Elmo.

Claude capacity is organization-wide. The plan page shows assignments across all brands, while **Settings → LLMs** shows and edits the assignments for the current brand.

Disabling a prompt also disables its Claude run. Removing paid capacity may require you to remove assignments first so the workspace stays within its new allowance.
