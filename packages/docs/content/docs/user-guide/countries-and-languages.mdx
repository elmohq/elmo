AI answers change with where a question is asked from and the language it is asked in. Every prompt has a **country** it is asked from and a **language** it is written in. Both start out sensible, so you only touch them when you track more than one.

## Countries

Every brand has a **Default Country** under **Settings → Brand**, which starts as **United States**. Prompts are asked from it unless they choose their own.

In **Settings → Prompts**, the **Country** column sets a prompt's own country. **Default** follows the brand.

Country is best effort. Each model is told the country where its provider accepts one, and otherwise answers from the provider's usual location. Every model runs every prompt either way. **Settings → LLMs** lists what each of your models does with countries and languages.

Changing a prompt's country does not translate it, and the prompt's earlier answers stay in its history.

## Languages

When you save a prompt, Elmo detects the language it is written in and shows it in the **Language** column. Brand and competitor names are ignored. If the detection is wrong, which is most likely on very short prompts, choose the language yourself and it stays as you set it.

The language reaches every model through the prompt's wording. Google's surfaces also take it as their interface language.

## Variants and Translations

To ask the same question in another language, open the **⋯** menu on a prompt in **Settings → Prompts**, click **Translate**, and choose the languages. Elmo adds a [variant](/docs/user-guide/settings#prompt-settings) under the prompt for each one, asked from the same country. Change a variant's country in its **Country** column if it should be asked from somewhere else.

A translation is not tracked until you save. Edit the wording first if it isn't how your customers would ask. Translations are stored, so translating the same text into the same language again costs nothing and returns the same wording.

## What It Costs

Every prompt is tracked on its own: it runs on each model you track, on your schedule. A variant or a translation is another prompt, so asking one question in three languages costs three prompts.

- **Self-hosted** — you pay your providers for each run. Adding a prompt shows what one prompt costs in provider calls a day and an estimated monthly cost, and the translate dialog shows the total for what you are about to add. The estimates use each provider's published prices, not your invoices.
- **Elmo Cloud** — each prompt counts toward your plan's prompt limit.

## Filtering by Country and Language

Once a brand's prompts are asked from more than one country, a **Countries** filter appears next to **Tags** on the overview, Visibility, Sentiment, Citations, Share of Voice, Query Fan-Out, and Responses pages. A **Languages** filter appears the same way once they are written in more than one language. The two work independently: pick English to see every English prompt whatever its country, or combine it with a country to narrow further.

## API

Prompts carry `country` and `language`, which are null where the prompt follows its brand, and `effectiveCountry` and `effectiveLanguage`, which are what the prompt is actually asked from and in. Brands carry the default `country` and `language`. The analytics endpoints and the prompt list take `countries` and `languages`, each a comma-separated list of codes such as `DE,CH` and `de,fr`; a code that isn't in the supported lists is a `400`. Runs report the `country` and `language` the provider was sent.

Requests that leave these fields out behave as they did before: prompts follow the brand, and a brand's country and language stay as they are.
