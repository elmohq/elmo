AI answers change with where a question is asked from and the language it is asked in. You choose the **country** a prompt is asked from. Elmo works out the **language** from the prompt's wording, so you only meet languages when you filter or translate.

## The Brand's Default Country

Every brand has a default country, which starts as **United States**. Prompts are asked from it unless they set their own. Change it under **Settings → Brand**.

Changing the default country moves every prompt that follows it, from the next run on. Each answer keeps the country it was asked from, but a prompt's history stays with the prompt, so after the change a country filter shows its earlier answers under the new country.

## A Prompt's Own Country

In **Settings → Prompts**, the **Country** column shows where each prompt is asked from:

- **Default** — the prompt follows the brand's country.
- A country such as **Germany** — the prompt is asked from there whatever the brand's default is.

Open the menu to pick a country. Before you choose, it shows which of the models you track can't answer from the highlighted country and what a prompt there costs.

Changing a prompt's country does not translate it, and the prompt's earlier answers move with it. To ask the same question somewhere else and compare the two, translate it instead.

## Variants and Translations

To track one question in several countries, click the translate icon on a prompt and pick where else to ask it. Each choice is a country with a language, such as **Switzerland · French**. Elmo adds a [variant](/docs/user-guide/settings#prompt-settings) under the original for each one, translated once where the language differs from the prompt's and copied as written where it is the same.

A translation is a draft until you save. Edit the wording first if it isn't how your customers would ask. Translations are stored, so translating the same text for the same country and language again costs nothing and returns the same wording.

To translate many prompts at once, select them and click **Translate**.

## What It Costs

Every prompt is tracked on its own: it runs on each model you track, on your schedule. A variant or a translation is another prompt, so asking one question from three countries costs three prompts.

- **Self-hosted** — you pay your providers for each run. The prompts page shows what one prompt adds in provider calls a day and an estimated monthly cost, and the translate dialog shows the total for what you are about to add. The estimates use each provider's published prices, not your invoices.
- **Elmo Cloud** — each prompt counts toward your plan's prompt limit. The prompts page shows how many you have used.

A model that can't answer from a prompt's country doesn't run that prompt, so a country fewer models cover costs less and tells you less.

## How Models Handle a Country

The country is sent to the provider, which answers as if the question came from there. For each model you track, one of three things happens:

- **Asked from the country** — the provider is told the country, and the answer is recorded with it.
- **No location** — a model called directly without web search has no location, so it answers the same question everywhere.
- **Skipped** — the provider can't be told the country. Rather than record another country's answer as this one's, the model doesn't run the prompt. Outside the United States this applies to providers with no country setting, since the United States is where they are assumed to answer from by default.

Elmo localizes by country because it is the one location every provider that localizes accepts. Cities and regions are supported by only a few.

The language reaches every model through the prompt's wording. Google's surfaces also take it as their interface language.

The prompt page shows the country a prompt is asked from. Click it to see whether the prompt sets it or follows the brand, and which models can't answer from there.

## How Languages Are Detected

There is no language to set. When you save a prompt, Elmo detects the language from its wording and records it, so a German prompt asked from the United States counts as German. Brand and competitor names are ignored. A prompt too short or too ambiguous to call counts as the brand's language, which is English unless the API changed it, and Indonesian, Malay, Croatian, and Serbian are too alike to tell apart reliably. A translated variant always carries the language it was translated into, and the [API](#api) can set a prompt's `language` directly where detection gets it wrong.

## Filtering by Country and Language

Once a brand's prompts are asked from more than one country, a **Countries** filter appears next to **Tags** on the overview, Visibility, Sentiment, Citations, Share of Voice, Query Fan-Out, and Responses pages. A **Languages** filter appears the same way once they are written in more than one language. The two work independently: pick English to see every English prompt whatever its country, or combine it with a country to narrow further.

## API

Prompts carry `country` and `language`, which are null where the prompt follows its brand, and `effectiveCountry` and `effectiveLanguage`, which are what the prompt is actually asked from and in. Brands carry the default `country` and `language`. The analytics endpoints and the prompt list take `countries` and `languages`, each a comma-separated list of codes such as `DE,CH` and `de,fr`; a code that isn't in the supported lists is a `400`. Runs report the `country` and `language` the provider was sent.

Requests that leave these fields out behave as they did before: prompts follow the brand, and a brand's country and language stay as they are.
