AI answers change with where a question is asked from and the language it is asked in. A market is those two things together: a country and a language, such as **Germany · German** or **Switzerland · French**.

## The Brand's Default Market

Every brand has a default market, which starts as **United States · English**. Prompts are asked in it unless they set their own. Change it under **Settings → Brand → Default Market**.

Changing the default moves every prompt that follows it, from the next run on. It does not translate their text. Each answer keeps the country it was asked from, but a prompt's history stays with the prompt, so after the change a market filter shows its earlier answers under the new market.

## A Prompt's Own Market

In **Settings → Prompts**, the **Market** column shows where each prompt is asked:

- **Default** — the prompt follows the brand's market.
- A market such as **DE · DE** — the prompt is asked there whatever the brand's default is.

Pick a market for a prompt to see, before you save, what each model you track does with it and what a prompt there costs.

Setting a prompt's market does not translate it, and the prompt's earlier answers move with it. To ask the same question in another market and compare the two, translate it instead.

## Variants and Translations

To track one question in several markets, click the translate icon on a prompt and pick the markets. Elmo translates the prompt once for each market and adds each translation under the original as a [variant](/docs/user-guide/settings#prompt-settings), set to that market.

A translation is a draft until you save. Edit the wording first if it isn't how your customers would ask. Translations are stored, so translating the same text for the same market again costs nothing and returns the same wording.

To translate many prompts at once, select them and click **Translate**.

## What It Costs

Every prompt is tracked on its own: it runs on each model you track, on your schedule. A variant or a translation is another prompt, so asking one question in three markets costs three prompts.

- **Self-hosted** — you pay your providers for each run. The prompts page shows what one prompt adds in provider calls a day and an estimated monthly cost, and the translate dialog shows the total for what you are about to add. The estimates use each provider's published prices, not your invoices.
- **Elmo Cloud** — each prompt counts toward your plan's prompt limit. The prompts page shows how many you have used.

A model that can't answer from a prompt's country doesn't run that prompt, so a market fewer models cover costs less and tells you less.

## How Models Handle a Market

The country is sent to the provider, which answers as if the question came from there. The language is carried by the prompt's wording; Google's surfaces also take it as their interface language. For each model you track, one of three things happens:

- **Asked from the country** — the provider is told the country, and the answer is recorded with it.
- **No location** — a model called directly without web search has no location, so it answers the same question everywhere. The language still comes through in the prompt.
- **Skipped** — the provider can't be told the country. Rather than record another country's answer as this one's, the model doesn't run the prompt. Outside the United States this applies to providers with no country setting, since the United States is where they answer from by default.

Elmo localizes by country because it is the one location every provider that localizes accepts. Cities and regions are supported by only a few.

The prompt page shows the market a prompt is asked in. Click it to see how each model runs that prompt.

## Filtering by Market

Once a brand's prompts are asked in more than one market, a **Markets** filter appears next to **Tags** on the overview, Visibility, Sentiment, Citations, Share of Voice, Query Fan-Out, and Responses pages. Pick one or more markets to see only the prompts asked there.

## API

Prompts carry `country` and `language`, which are null where the prompt follows its brand, and `market`, which is where the prompt is actually asked. Brands carry the default `country` and `language`. The analytics endpoints and the prompt list take `markets`, a comma-separated list written as language-country, such as `de-DE,fr-CH`; a market that isn't in the supported list is a `400`. Runs report the `country` and `language` the provider was sent.

Requests that leave these fields out behave as they did before markets: prompts follow the brand, and a brand's market stays as it is.
