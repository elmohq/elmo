---
title: Countries
description: Ask prompts from the countries your customers are in, and compare markets side by side.
---

AI answers depend on where they're asked from. The same question gets different sources, different shops, and different competitors in the UK than in the US, and Google only shows an AI Overview for some queries in some countries. Every prompt in Elmo is asked from one country, so its results describe that market.

## Choosing a country

Prompts start in the **United States**. To track another market, pick a country when you add the prompt on the **Prompts** settings page. **Add Multiple** takes several countries at once and adds every pasted line once per country. That's the quickest way to track the same questions in, say, the US, the UK, and Canada.

A saved prompt's country can't be changed. Changing it would mix two markets into one history, so to measure a prompt somewhere else, add it again in that country. Each copy is a separate prompt with its own history, and each one counts toward your prompt limit.

The prompt text is sent exactly as you write it, so write it in the language people in that market use. For anything more local than a country, put the place in the prompt itself (for example `best running shop in Manchester`).

## Filtering by country

Once a brand's prompts span more than one country, a **Countries** filter appears next to the tag filter on every dashboard page. Pick one country to see that market on its own, or several to see them combined. With no countries picked, every market is included. Each prompt also shows its country code in the prompt list.

The API and MCP server take the same filter as a `countries` parameter: comma-separated ISO 3166-1 alpha-2 codes, such as `countries=GB,IE`.

## Which platforms can answer from a country

Each provider localizes in its own way, and not every one can. For a prompt outside the US, Elmo only runs it on the platforms that can actually answer from that country, rather than storing a US answer under another country's name.

| Provider | Localized platforms |
| --- | --- |
| Cloro | All |
| Olostep | All |
| Oxylabs | All |
| DataForSEO | All scraped surfaces. Not targets pinned to a model version (LLM Responses) |
| BrightData | ChatGPT and Google AI Overview |
| SearchApi | Google AI Mode and Google AI Overview |
| OpenAI API, Anthropic API | Targets with web search on (`:online`) |
| Mistral API, OpenRouter | None with web search on |

A model called **without** web search answers the same everywhere, so it runs every prompt in every country. Each run records the country it was localized to, which the API returns as `country` on every run. That field is `null` when the platform takes no location.

Elmo sends the country, not a language. The prompt's own wording decides the language of the answer.
