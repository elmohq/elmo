Elmo provides a REST API for managing workspaces and retrieving analytics programmatically. All endpoints require Bearer token authentication.

**Base URL:** `/api/v1`

## Authentication

Include your API key in the `Authorization` header:

```http
Authorization: Bearer YOUR_API_KEY
```

Workspace admins can issue scoped API keys from **Settings → API keys**. Keys can be restricted to selected brands and given an expiry date. Instance-wide admin keys can also be configured server-side via the `ADMIN_API_KEYS` environment variable.

## Endpoints

Browse the available endpoints in the sidebar, grouped by resource:

- **Brands** — manage brand records
- **Tools** — one-shot helpers (e.g. brand analysis) that don't persist anything
- **Prompts** — manage brand prompts
- **Competitors** — manage brand competitors
- **Snapshots** — aggregated analytics snapshots for prompts
- **Reports** — generate and retrieve AI Share of Voice reports
- **Analytics** — visibility, share of voice, citations, platform, prompt, and query fan-out metrics
- **Runs** — retrieve prompt evaluation runs
- **Tags** — list, rename, merge, and remove prompt tags
- **Opportunities** — retrieve the latest generated brand opportunities
- **Organizations and billing** — inspect workspace and subscription state
- **Platforms** — list available answer engines
