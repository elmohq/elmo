Elmo provides a REST API for managing brands, prompts, and snapshots programmatically. All endpoints require Bearer token authentication.

**Base URL:** `/api/v1`

## Authentication

Include your API key in the `Authorization` header:

```http
Authorization: Bearer YOUR_API_KEY
```

Authentication depends on the deployment:

- **Cloud:** create an API key from the workspace billing settings. The key belongs to that workspace, can only access its brands and related resources, and requires active plan access. Write requests also enforce the workspace's current brand and tracked-prompt capacity.
- **Local and whitelabel:** configure one or more instance-wide keys with the `ADMIN_API_KEYS` environment variable. Existing API behavior is unchanged.

Cloud keys return `404 Not Found` for resources owned by another workspace. Capacity and retained-history conflicts return `409 Conflict`; a plan or permission that does not allow the request returns `403 Forbidden`.

## Deployment availability

| Resource operation | Cloud workspace key | Local / whitelabel key |
| --- | --- | --- |
| Brands: GET, POST, PATCH | Yes, workspace-scoped | Yes, instance-scoped |
| Prompts: GET, POST, PATCH | Yes, workspace-scoped | Yes, instance-scoped |
| Prompt snapshots: GET | Yes, workspace-scoped | Yes, instance-scoped |
| Competitors: GET, POST, PATCH | Yes, workspace-scoped | Yes, instance-scoped |
| Prompt DELETE | Returns `409`; use PATCH with `enabled: false` | Yes |
| Competitor DELETE | Not available (`403`) | Yes |
| Tools and reports | Not available (`403`) | Yes |

Cloud prompt mutations reconcile the workspace's plan-based tracking targets and cadences. They do not create the legacy per-prompt scheduler used by local and whitelabel deployments.

## Endpoints

Browse the available endpoints in the sidebar, grouped by resource:

- **Brands** — manage brand records
- **Tools** — one-shot helpers (e.g. brand analysis) that don't persist anything
- **Prompts** — manage brand prompts
- **Competitors** — manage brand competitors
- **Snapshots** — aggregated analytics snapshots for prompts
- **Reports** — generate and retrieve AI Share of Voice reports
